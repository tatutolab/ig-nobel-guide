# イグノーベル賞図鑑

1991〜2026年の公式歴代一覧掲載357件を日本語で閲覧するWebアプリ。

## GitHub Pagesで公開
1. リポジトリを作成（例：ig-nobel-guide）。
2. ZIPを展開し、index.html、README.md、.nojekyllをリポジトリの一番上へアップロード。
3. Settings → Pages → Deploy from a branch を選択。
4. mainブランチ、/(root) を指定して保存。
5. Pagesに表示されるURLを開く。

ビルド、APIキー、外部ライブラリは不要。357件のデータはindex.html内に収録しています。

## 機能
- キーワード・年・部門で絞り込み
- YouTubeで関連動画を検索
- 年別授賞式動画（公式掲載URL、または検索）
- お気に入り（ブラウザ内保存）
- ランダムに1件を表示

お気に入りの保存キー：ignobel-favorites-v1。
現在の公開サイトとGitHub Pagesは別のURLなので、お気に入りは自動では引き継がれません。
